# Cinematic Listings

## Promise
Agent supplies existing professional listing photography and property details. We turn them into a premium interactive listing microsite in 24–48 hours.

## v1 inputs
- 20–40 listing photos
- address or approved display name
- price
- beds/baths/square footage
- property description
- agent name/headshot/logo/contact
- MLS/Zillow or brokerage URL
- optional video/floorplan

## v1 output
- custom shareable listing URL
- desktop + mobile cinematic experience
- property facts
- gallery/spatial exploration
- location/neighborhood moment
- agent branding
- viewing/contact CTA
- outbound link to canonical listing
- social preview metadata
- basic analytics hook

## Treatments
CINEMATIC — emotional, spatial, luxury.
EDITORIAL — restrained, architectural, information-forward.
Future: HERITAGE / MODERN / LAND.

## Do not build yet
Billing, multi-tenant dashboard, CRM, AI chatbot, full brokerage CMS. Prove repeatable output first.
