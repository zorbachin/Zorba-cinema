# Zorba Cinema

Canonical production repository for Zorba's cinematic web experiences.

## First commercial product
**Cinematic Listings** — turn ordinary residential listing photography into a premium interactive property experience.

Initial prototypes:
1. **17 OCEAN** — cinematic California luxury concept.
2. **Columbus 01** — realistic upper-end residential prototype for mainstream US agents.

This repository is the source of truth for code, assets, manifests and builder handoffs. Do not create parallel implementations without an explicit experiment.

## Commercial target
- $1,000: productized cinematic listing from agent photography.
- $1,500–$2,000: signature listing with deeper customization/video.
- $3,500–$5,000+: bespoke agent/brokerage immersive site.

All concept properties must be clearly labeled as concepts. Never fabricate a client, listing, testimonial, publication quote or performance metric.
